Privacy policy

Effective July 6, 2026

What the connector does

The RosterLab ESPN Connector lets you sync an ESPN fantasy baseball league into RosterLab. You sign in on ESPN's website. The extension then requests the league data using the ESPN session already held by your browser and returns that league data to the open RosterLab tab.

Data the connector does not collect

The connector does not read, receive, or store your ESPN password, verification codes, or session-cookie values. It does not use analytics, advertising, or a RosterLab server. It does not sell or share personal data.

League data and temporary state

ESPN returns league settings, teams, rosters, standings, ownership, and available player projections. The extension passes that response directly to RosterLab in your browser. RosterLab normalizes the response and saves the connected league in local browser storage so it remains available after a refresh.

While a connection is open, the extension keeps random request and operation IDs, the two browser-tab IDs, the selected league, season, and team IDs, and connection timestamps in Chrome's in-memory session storage. It removes that state after success, cancellation, failure, or ten minutes from the start of the connection. Chrome also clears it when the browser restarts or the extension updates.

Permissions

  • Access to RosterLab pages lets the extension receive a connection request and return league data to the same tab.
  • Access to ESPN fantasy baseball pages lets the extension recognize the league you open.
  • Access to ESPN's fantasy read API covers that API host because Chrome host permissions are origin-wide. The connector code requests only the fixed baseball league endpoint through your existing ESPN session.
  • Session storage and alarms let the extension coordinate the tabs and discard an unfinished connection after ten minutes.

The extension does not request Chrome's cookie permission or access unrelated websites.

Your control

Remove the extension at any time from your browser's extension settings. In RosterLab, choose "Restore demo league" to remove the imported league from local storage. Saved trade scenarios and the player watchlist remain until you delete them in RosterLab or clear this site's browser storage.

ESPN notice

RosterLab is not affiliated with or endorsed by ESPN. ESPN does not publish a supported fantasy API, so this connector may stop working if ESPN changes its website or private endpoints.
